
# 🎮 Number Guessing Game & Word Counter

## 📌 Project Overview

This is a beginner-friendly Python project that includes two applications:

1. Number Guessing Game
2. Word Counter Tool

The project helps beginners understand Python loops, random numbers, file handling, and string manipulation.

## 🚀 Features

### 1. Number Guessing Game
- Generates a random number between 1 and 100.
- Gives the user 7 attempts to guess.
- Provides higher or lower hints.
- Calculates scores based on attempts.
- Displays a winning or losing message.

### 2. Word Counter
- Reads text from a .txt file.
- Counts total words.
- Counts unique words.
- Displays word frequency.
- Handles missing files.
